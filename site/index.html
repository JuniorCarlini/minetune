O que vem pronto

Tudo o que um servidor precisa para rodar de verdade

Sem improviso: servidor otimizado, painel para configurar sem editar arquivos, backups que saem da máquina e caminhos claros para abrir para a internet.

Servidor otimizado

Paper 26.2 por padrão, ou Purpur, Fabric, NeoForge e Vanilla. Java 25, flags Aikar e patches de desempenho.

Painel web próprio

Status com gráficos, configurações validadas, regras do jogo, jogadores, plugins do Modrinth e console ao vivo.

Backups criptografados

restic incremental e deduplicado, agendado ou na hora, com restore seguro que desfaz a troca se algo falhar.

Crossplay com Bedrock

Geyser e Floodgate com um toggle: celular, console e Windows entram sem conta Java.

Seguro por padrão

Painel só no localhost, RCON fechado e Docker acessado por proxy que não deixa criar containers.

Roda em qualquer lugar

PC de casa, VPS ou EasyPanel. Port forward, túnel playit.gg para CGNAT ou VPS como ponte.

Início rápido

No ar em poucos minutos

Precisa só de Docker com Compose v2, make e openssl. Reserve pelo menos 6 GB de RAM.

1

Baixe o projeto

$ git clone https://github.com/JuniorCarlini/minetune.git
$ cd minetune
2

Gere os segredos e suba

# gera senhas no .env
$ make init
# ~1–3 min no 1º boot
$ make up
3

Abra o painel e jogue

# painel (PANEL_PASSWORD)
http://localhost:8080
# jogo
localhost:25565
Backups

Seu mundo guardado fora da máquina

Cada snapshot envia só o que mudou e é criptografado antes de sair. O salvamento pausa durante a cópia, então nada fica pela metade.

Disco local Cloudflare R2 AWS S3 RustFS (S3 próprio)
