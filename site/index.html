O que vem pronto

Tudo o que um servidor de Minecraft precisa para rodar de verdade

Sem improviso: servidor otimizado, painel para configurar sem editar arquivos, backups que saem da máquina e caminhos claros para abrir para a internet.

Servidor otimizado

Paper 26.2 por padrão, ou Purpur, Fabric, NeoForge e Vanilla. Java 25, flags Aikar e patches de desempenho.

Painel web próprio

Em português e sem jargão: estado do servidor, jogadores, regras do jogo, configurações, plugins do Modrinth e backups, com avisos que dizem o que fazer.

Backups criptografados

restic incremental e deduplicado, agendado ou na hora, com restore seguro que desfaz a troca se algo falhar.

Crossplay com Bedrock

Geyser e Floodgate com um toggle: celular, console e Windows entram sem conta Java.

Seguro por padrão

Painel só na própria máquina, acesso remoto ao console fechado e Docker acessado por proxy que não deixa criar containers.

Roda em qualquer lugar

PC de casa, VPS ou EasyPanel. Port forward, túnel playit.gg para CGNAT ou VPS como ponte.

Início rápido

Seu servidor de Minecraft no ar em poucos minutos

Precisa só de Docker com Compose v2, make e openssl. Reserve pelo menos 6 GB de RAM.

1

Baixe o projeto

$ git clone https://github.com/JuniorCarlini/minetune.git
$ cd minetune
2

Gere os segredos e suba

# gera senhas no .env
$ make init
# ~1–3 min no 1º boot
$ make up
3

Abra o painel e jogue

# painel (PANEL_PASSWORD)
http://localhost:8080
# jogo
localhost:25565

Perguntas frequentes

Dúvidas comuns antes de subir o servidor

O que é o Minetune?

É um projeto para rodar um servidor de Minecraft em Docker já organizado para uso real: servidor otimizado, painel web em português, backups criptografados e guias para colocar no ar em casa, numa VPS ou no EasyPanel.

Como criar um servidor de Minecraft com o Minetune?

Com Docker instalado, clone o repositório e rode make init para gerar as senhas e make up para subir tudo. O painel abre em localhost:8080 e o jogo em localhost:25565.

Quais tipos e versões de servidor são suportados?

Paper (padrão), Purpur, Fabric, NeoForge e Vanilla. O painel lista as versões oficiais de cada um, das mais recentes para as mais antigas, e avisa quando uma versão antiga precisa de outra imagem de Java.

Onde ficam os backups do mundo?

No disco local por padrão, ou fora da máquina em Cloudflare R2, Amazon S3 ou num S3 próprio como RustFS. Os backups são incrementais e criptografados com restic, e o destino é configurado pelo painel com teste de conexão.

Dá para jogar pelo celular ou console?

Sim. Ligando o crossplay com Bedrock nas configurações, o Minetune instala Geyser e Floodgate, e jogadores de celular, console e Windows entram pela porta 19132 sem precisar de conta Java.

Preciso abrir portas no roteador?

Não obrigatoriamente. Com IP público dá para usar port forward; sem IP público ou atrás de CGNAT, o túnel playit.gg funciona sem abrir portas. Também é possível usar uma VPS como ponte ou hospedar no EasyPanel.

Quantos jogadores o servidor aguenta?

O máximo de jogadores é uma configuração do painel, de 1 a 1000. O limite real é a máquina: processador, memória e internet. Dezenas de jogadores cabem numa máquina comum; centenas pedem máquina forte e, em geral, vários servidores ligados por um proxy.
